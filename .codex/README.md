# Development continuity

This internal guide points maintainers and coding agents to the persistent project documentation needed to resume work after a break or in a new session.

- [AGENTS.md](../AGENTS.md): rules, invariants, and reading order.
- [Project status](../docs/project-status.md): current snapshot, completed checks, and next step.
- [Roadmap](../todolist.md): work ordered toward the beta release.
- [Changelog](../CHANGELOG.md): added or changed behavior.
- [Architecture decisions](../docs/decisions): decisions and rationale.
- [Contributing guide](../CONTRIBUTING.md): development workflow.
- [Testing guide](../docs/testing.md) and [release guide](../docs/release.md): validation and publishing.

At the end of each development session, update `docs/project-status.md`, `todolist.md`, and `CHANGELOG.md` so they reflect the work that was actually completed.
